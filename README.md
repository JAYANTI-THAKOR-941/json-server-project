# JSON Server Storefront

React product display and administration exercise with JSON-backed data.

## Project structure

- `db.json`
- `src/admin/ProductManagement.jsx`
- `src/pages/Product.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/json-server-project.git
cd json-server-project
```

Run `npm install`, configure and start the local JSON API, then run `npm run dev`.
